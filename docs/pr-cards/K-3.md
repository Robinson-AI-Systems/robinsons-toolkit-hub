## K-3a source and behavior
- Existing Stripe functions copied verbatim to proposed-now `packages/core/src/oauth.js` and `crypto.js`.
- Package exports named subpaths only. No credential is read at import time.
- Security tests retain the upstream assertion bodies, with import rewiring and a
  three-method test store; no real secrets, provider calls, or SQL changes.
- Login input → injected `recordLoginAttempt` → `countRecentFailedLogins`
  → lockout/wrong/ok, with only approved success updates; no service API calls.
- Encryption input → configured 32-byte key + AAD → v1 AES-GCM ciphertext;
  invalid key, changed AAD or tampering fail closed; no plaintext fallback.
