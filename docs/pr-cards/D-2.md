## Implementation and acceptance

- Supports MCP initialize, ping, tools/list and tools/call via UTF-8 newline-delimited
  JSON-RPC 2.0 on stdio, with no secret/status text on stdout.
- Six tools per authorized service: search, describe, call, batch (reads only),
  result and whoami. Tool names prefixed by configured alias. The local broker
  never widens a remote pass or claims to complete a denied remote action.
- Cap request lines, tool catalog token budget, result inline size. Tool-level
  server failures set isError and expose sanitized errors, never tokens.
- Two independently started HTTP fakes are used for list, catalog search,
  describe, read, unconfirmed guarded write, confirmed write, read-only denial,
  batch and real stdio framing. Missing-pass service remains disabled.
- Exact PR head green under check, unit, DB and aggregate ci. No live account.
- Successor D-3 builds encrypted GitHub relay (owner private repo/keys are
  environment gates, not prerequisites for implementing safe test code).
