### Query and caller-grant security closeout criteria

The actual 019 projection contains immutable `grant_id`. Original scoped reader permitted historical rows by **service name**, which could reveal rows for an expired or replaced grant when a new independent grant to that same service was active. This targeted source change joins the original exact grant identity against verified unexpired server-grant SQL and binds opaque cursor scope to a **hash** of all current grant identities, tool and UTC range. A replaced grant invalidates prior-page continuation; no bearer or raw grant ID enters the cursor. Owner inspection retains independently password-verified full historical audit and source outcomes. An ordinary long list is shortened to fit 7,600 bytes with a real next-page cursor rather than failing the entire read. Historical audit rows are never edited.
