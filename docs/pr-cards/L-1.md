# L-1 — Local files, shell and git tools

Status: IN_PROGRESS. Design: BATCH-L §1, §4 L-1. Depends on D-2 (MERGED).
Baseline: Hub main 6447c80180e400a197afe93667b15460b2f296c8, verified October 12, 2026.
Owner-approved implementation; no new credentials, migrations, provider activation, paid resources, or hosted tools.

## Scope and risk
Only `rtool mcp --local FOLDER[,FOLDER...]` may expose local tools, never hosted Hub or relay.
Read-only files first (#126 candidate); later independent guarded shell and git slices.
Canonicalize 1–8 owner-selected folders; refuse relative traversal and resolved paths outside roots.
Limit read to regular UTF-8 files ≤4096 bytes; never silently return partial content.
Bound listing and keep local tool schemas compact. No local access in default `rtool mcp`.
Existing standalone servers, passes, permissions, and account context are unchanged.

## First slice: explicitly enabled file tools
Files: packages/cli/src/local-files.js, mcp.js, commands.js, test/local-files.test.js.
`local.file_list`, `local.file_stat`, `local.file_read` accept relative path and indexed approved root.
No server token or remote call; resolve on each request, refuse outside canonical folder, refuse oversize/binary reads.
Tests: opt-in invisibility, usable listing/stat/read, traversal and symlink escape refusal, oversized read, invalid root/duplicates.
Proof: targeted Vitest, npm check, npm test and exact-head CI, full diff self-review and required checks.

## Remaining acceptance
- Shell: strict read-only allow-list; nonallowlisted commands require explicit `confirm: true`,
  bounded timeout and stdout/stderr cap, no sudo, no execution outside authorized folders.
- Git: read-only status, diff, log scoped to approved roots; no implicit write/push ability.
- Directory symlink/race security reviewed before any shell is exposed; avoid hosting local handlers.
- Full smoke test via `rtool mcp --local`; default mode still zero local capabilities.
- Update STATUS and work index as the implementation advances; no placeholder or acceptance claim
  for missing shell/git functions.
