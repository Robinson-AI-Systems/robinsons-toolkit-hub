| Assumption | Current repository/source | Resolution |

## Observable acceptance

- Local stdio MCP `tools/list` and `tools/call` show Ollama capabilities only with explicit `--local` and `OLLAMA_BASE_URL` set to a strict loopback HTTP origin. Without either, zero Ollama methods are offered. Hosted and relay remain untouched.
- Real local `/api/version`, `/api/tags`, `/api/ps`, `/api/generate`, `/api/chat`, `/api/embed` with versioned Ollama-compatible JSON. Model names must resolve to already downloaded local models (nonempty file size and digest); no cloud aliases, pull, load-only, download, model deletion, function-calling or implicit remote fallback.
- One shared bounded request transport with explicit per-request deadline (2–60 seconds), no redirects, fixed methods and paths, no forwarded credentials/environment, streaming disabled, finite response size, UTF-8/JSON validity and sanitized errors. No silent output truncation.
- Strict schema/argument validation, bounded prompt and chat turns; embeddings must be fully returned within MCP cap or explicitly saved with confirmation into a new file in one approved root. A failed/stale/missing capture never overwrites.
- Actual synthetic local HTTP server tests plus MCP catalog/stdio integration verify full positive paths, refusal, timeout, redirect, oversized response, cloud/nonloopback refusal, missing config isolation, model mismatch, no upstream pass headers, and unchanged local file/Git availability.
- Source CI, lint, security and review are required before merge. Actual owner-PC/GPU performance and installed Ollama model compatibility remain independent acceptance; no agent installs, downloads or configures software on the owner's computer.

## Integration boundary

`packages/cli/src/local-ollama.js` supplies fixed handlers and catalog; `local-files.js` delegates only opt-in calls; `mcp.js` emits catalog based on the explicitly supplied env and established local door; `commands.js` passes env from the existing CLI execution context. No new provider, hosted API, grant, migration, secret or financial authority.

Official API reference: https://docs.ollama.com/api/introduction and https://docs.ollama.com/api/chat.
