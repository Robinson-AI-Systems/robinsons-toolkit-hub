## Drift check A — source and primary docs

| Assumption | Actual source/docs | Design correction |
|---|---|---|
| Browser is a cloud Hub tool | Local only in `rtool mcp --local`; hosted process cannot reach owner machine | No Hub/HTTP deployment, local opt-in only |
| Any site may be visited | Local webpage can trigger redirects, subresources and WebSockets | Exact HTTPS origin allowlist (loopback HTTP explicitly selected); block disallowed redirects and *all* WebSockets |
| Browser intercept sees every request by default | Playwright `context.route` cannot reliably intercept Service Worker-served fetches | Browser context `serviceWorkers:'block'`; install route before navigation, deny other origins |
| Browser binaries are bundled | Current repo has no Playwright dependency/binary | Only opt into locally installed `playwright` and Chromium; missing runtime disables only browser tools |
| Screenshot can be returned in MCP JSON | Screenshot bytes can overwhelm model context or leak file data | Restrictive create-only PNG file under an approved root, return path+size only |
| Can click or enter credentials automatically | L-4 separately requires visible guided settings and owner approval | No credential entry, arbitrary JS, form mutation, click, browser profile reuse or visible settings automation in L-3 |

## Whole-subsection acceptance

- Four local-only tools: `local.browser_status`, `local.browser_visit`, `local.browser_links`, `local.browser_screenshot`. Only listed when `--local`, valid exact allowed-origin config and locally installed Playwright runtime are all present; no default hosted/local functionality expansion.
- Fixed verified context per operation, fresh browser, sandboxed Chromium headless, no persisted cookies or storage, service workers blocked, network route intercepting ALL requests, no WebSockets, downloads/popups and disallowed origins refused. A redirect to any other origin fails closed even after navigation; no cross-host screenshot.
- 1–8 owner-selected exact HTTPS allowed origins, optional explicitly allowed HTTP loopback. No wildcard, file/data/ftp/internal protocol, auth-in-URL or arbitrary browser command execution. User-specified URL must match an approved origin.
- Browser read extracts bounded title, final URL, body summary or at most 20 matching links. Screenshot is a bounded PNG buffer stored privately under selected root with no overwrite/symlinks/path traversal or Git metadata, confirmed by owner; reply only path, bytes and title, never image bytes.
- 1–15s navigation deadline, bounded results, full context/browser cleanup on both success and failures. Missing module/browser or invalid config disables affected tools and preserves file/Git/Ollama independently.
- Unit/stdio tests with injected Playwright context: allowed pages, refused host/subresource/redirect, abort WebSocket, safe storage/no-download, screenshot creation and no-overwrite, closing resources when rejected and no leaking profile/credentials; exact-head mandatory CI/security/review.
- Real installed owner-PC Chromium/browser network acceptance OPEN separately. This code does not assert browser kernel confinement, provider identity or L-4 owner settings approval.

Primary Playwright design references: https://playwright.dev/docs/api/class-browsercontext and https://playwright.dev/docs/browsers.
